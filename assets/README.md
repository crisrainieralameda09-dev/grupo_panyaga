# Assets

Place the following files here:

- `music.mp3` — background song for the "PLAY OUR SONG" button
- `memory1.jpg` … `memory6.jpg` — gallery photos (lunch memories)
- `video.mp4` — the "JOY IN MOTION" video (optional; a public fallback plays if missing)

If files are missing, the site still works: the music button simply won't play audio, and gallery images fall back to a blue placeholder.
